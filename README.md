# Sequencing Animations 🎬⚡

This project demonstrates how to run a series of animations in sequence using the **Web Animations API** and JavaScript asynchronous programming.

## 📌 Description

Three images are animated one after another. Each animation starts only after the previous one has finished. The animation rotates and scales the images until they disappear.

The sequencing is handled using `Promises` and `async/await`, ensuring proper control over the animation flow.

---

## 🚀 Features

- Sequential animations (one after another)
- Web Animations API (`element.animate()`)
- Promise-based control using `.finished`
- Async/Await implementation
- Clean and simple UI

---

## 🧠 Concepts Used

- JavaScript Promises
- async / await
- Web Animations API
- DOM manipulation
- CSS basic styling
